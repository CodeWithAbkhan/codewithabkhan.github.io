# CodeWithABKhan portfolio

Production source for [codewithabkhan.github.io](https://codewithabkhan.github.io/).

This is a Vite, React, TypeScript, and Three.js portfolio for Abdul Wahab. It presents verified client history, selected public work, AI agent systems, cross-platform .NET products, and database-heavy business software.

## Local development

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run build
npm run preview
```

GitHub Actions builds `dist/` and deploys it through GitHub Pages.
